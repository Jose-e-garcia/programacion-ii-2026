# Cajero Automático

Nombre: Jose Ernesto Garcia
Carnet: 3121
Curso: Programación II
Sección: C

## Descripción

Programa de consola en Java que simula las operaciones básicas de un cajero automático.
Permite consultar saldo, realizar depósitos, retiros normales y retiros con comisión,
además de mostrar un resumen de las operaciones realizadas durante la sesión.

## Ejecución

Ejecutar la clase principal `CajeroAutomatico` desde IntelliJ IDEA.
