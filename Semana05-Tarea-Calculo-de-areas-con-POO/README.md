# Cálculo de áreas con POO

## Descripción

Aplicación de consola desarrollada en Java para calcular el área de diferentes figuras geométricas utilizando programación orientada a objetos.

## Figuras implementadas

- Círculo
- Rectángulo
- Triángulo

## Instrucciones para ejecutar

1. Abrir el proyecto en un entorno de desarrollo compatible con Java.
2. Ejecutar la clase `Main`.
3. Observar en la consola el nombre y el área calculada de cada figura.
