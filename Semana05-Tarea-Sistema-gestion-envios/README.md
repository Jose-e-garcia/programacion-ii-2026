# Sistema de Gestión de Envíos

## Descripción

Aplicación de consola desarrollada en Java para registrar envíos nacionales e internacionales y calcular su costo final según el tipo de envío.

## Objetivo

Aplicar conceptos de Programación Orientada a Objetos para desarrollar un sistema de gestión de envíos.

## Temas aplicados

- Clases y objetos
- Atributos y métodos
- Encapsulamiento
- Constructores
- Herencia
- Sobrecarga de métodos
- Sobrescritura de métodos
- Polimorfismo
- Validación de datos
