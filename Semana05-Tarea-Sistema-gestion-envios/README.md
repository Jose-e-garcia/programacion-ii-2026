# Sistema de Gestión de Envíos

## Descripción

Aplicación de consola desarrollada en Java para registrar envíos nacionales e internacionales y calcular su costo final según el tipo de envío.

## Objetivo

Aplicar conceptos de Programación Orientada a Objetos para desarrollar un sistema de gestión de envíos.

## Temas aplicados

- Clases y objetos
- Atributos y métodos
- Encapsulamiento
- Constructores
- Herencia
- Sobrecarga de métodos
- Sobrescritura de métodos
- Polimorfismo
- Validación de datos

## Estructura del proyecto

```text
src/
├── Envio.java
├── EnvioNacional.java
├── EnvioInternacional.java
└── Main.java

## Instrucciones para ejecutar

Abrir el proyecto en IntelliJ IDEA.
Ejecutar la clase Main.
Seleccionar una opción del menú.
Ingresar los datos solicitados.
El sistema calculará y mostrará el costo del envío.

## Resultado esperado

El programa permite registrar envíos nacionales e internacionales, validar los datos ingresados y mostrar el costo base, los cargos adicionales y el costo final del envío.
