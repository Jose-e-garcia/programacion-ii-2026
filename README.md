# programacion-ii-2026

Variables y operadores: Calculadora de edad
El programa solicita información al usuario para hacer el cálculo de edad aproximada en años y en meses, así como el nombre para que sea presentando como "RESULTADO" al final de donde se ingresó la información, tal y como se muestra en las imágenes que a continuación detallan el código y el resultado en la consola

El programa solicita:

Nombre.
Carné.
Año de nacimiento.
Año actual.

Posteriormente debe calcular y mostrar:

Edad aproximada.
Edad aproximada en meses.
Si la persona es mayor de edad.
